# Citations: what the deck says, what the source says

Every cited paper, post, and talk in *Experience Is Abundant. Knowledge Is
Distilled.*, checked against the source text on 2026-09-26. Slide numbers follow
the `best` branch's 24-slide order (2026-09-28): the problem (1–6), a thesis slide (7), then store (8–10), distill (11–16), trace (17–19) and the close (20–24). Backup slides after Thanks are numbered B1 (the ladder) and B2 (consolidation). Each row gives the claim as it appears on the slide,
what the source actually says (quoted where it matters), and a verdict.

Verdicts: **OK** the slide says what the source says. **Nuance** true but the
slide compresses or generalises; a word or two would make it exact. **Overstated**
the slide claims more than the source supports; change the copy. **Unverified**
could not be checked against a written source.

The fixes are collected in §2. Source summaries are in §3. Method in §4.

## 3. Source summaries

**When Continual Learning Moves to Memory: A Study of Experience Reuse in LLM Agents.** Hu, Long, Wang. arXiv:2604.27003, April 2026. Shows that memory-augmented agents do not escape the stability–plasticity dilemma; it reappears as competition between old and new experiences at retrieval time under a limited context window. Sequential-task experiments on ALFWorld and BabyAI: abstract procedural memories transfer better than detailed trajectories, negative transfer hurts hard cases disproportionately, and finer-grained memory organisation can cause forgetting. *Used on slide 5 for the "more memory can hurt" turn.*

**Improving Language Agents through BREW (Bootstrapping expeRientially-learned Environmental knoWledge).** Kirtania, Biyani, Gupta, Bajpai, Iyer, Gulwani, Soares. Microsoft and collaborators. arXiv:2511.20297, November 2025, revised July 2026. Builds a retrievable knowledge base of natural-language "recipes" from an agent's own runs, using a reward-guided Monte Carlo tree search (EG-MCTS) that optimises recipe accuracy and retrievability. Evaluated on OSWorld, τ²-Bench and SpreadsheetBench: 10–20% higher task success and 10–15% fewer steps than the base agent, while some existing memory baselines score below memoryless. *Used on slides 5, 12, 14 and B1.*

**Remember Me, Refine Me (ReMe): A Dynamic Procedural Memory Framework for Experience-Driven Agent Evolution.** Cao, Deng, Yu, Zhou, Liu, Ding, Zhao. arXiv:2512.10696, December 2025; ACL 2026 Findings. Names "passive accumulation" as the failure of append-only procedural memory and proposes three mechanisms: multi-faceted distillation, context-adaptive reuse, and utility-based refinement that prunes outdated memories. State of the art on BFCL-V3 and AppWorld; reports a "memory-scaling effect" where Qwen3-8B with ReMe (55.03% Pass@4) exceeds vanilla Qwen3-14B (54.65%). Memory quality is judged by an LLM, not by re-execution. *Used on slides 14, 16 and B1.*

**SKILL-KD: Contrastive Skill Distillation for LLM Agents.** Shi, Dou, Zhu, Tao, Jin, Kang, Zhou, Weng. arXiv:2607.28048, July 2026. Treats skills as the medium of distillation between a weak student and a stronger teacher: given a student failure and the teacher's trajectory on the same task, it writes a textual skill patch capturing the actionable discrepancy, re-runs the student to test it, and refines. Maintains trace-linked edit histories and a drift-aware consolidation step deciding whether a patch adds, edits, deletes or is skipped. *Used on slides 12 and B1.*

**RecMem: Recurrence-based Memory Consolidation for Efficient and Effective Long-Running LLM Agents.** Dai, Deng, Guan, Tian, Yao, Yan, Cheng. arXiv:2605.16045, May 2026; ACL 2026 Findings. Stores interactions in a "subconscious" layer indexed by lightweight embeddings and calls an LLM to extract episodic and semantic memory only when semantically similar interactions recur. Cuts memory-construction token cost of three state-of-the-art systems by up to 87% while exceeding their accuracy. *Used on slide B2.*

**Sleep-time Compute: Beyond Inference Scaling at Test-time.** Lin, Snell, Wang, Packer, Wooders, Stoica, Gonzalez. Letta and UC Berkeley. arXiv:2504.13171, April 2025. Lets a model reason about a context before queries arrive, pre-computing useful quantities. On Stateful GSM-Symbolic and Stateful AIME it reduces the test-time compute needed for the same accuracy by about 5×. A reasoning-benchmark result the deck uses as an analogy for off-path consolidation. *Used on slide B2.*

**Agent Memory Distillation: Empowering Small LLM Agents with Hierarchical Teacher Memory.** Kim, Kim, Hwang. arXiv:2608.07169, August 2026. Transfers structured knowledge from a large teacher agent to 4–8B students through three memory tiers built from successful teacher trajectories: workflow, subtask, and function. Workflow and subtask memory are injected at task start, function memory retrieved on error. Average gains of 27.2, 11.2 and 3.4 points on AppWorld, BFCL V3 and ToolSandbox; subtask memory contributes most; 4B students gain most. *Used on slides 14 and 16.*

**TRUSTMEM: Learning Trustworthy Memory Consolidation for LLM Agents with Long-Term Memory.** Yang, Paul, Srinivasan, Kulkarni, Chappidi. arXiv:2606.25161, June 2026. Identifies three ways memory updates go wrong, omission, corruption and hallucination, and trains the memory-writing agent with a Memory Transition Verifier that scores each update for coverage, preservation and faithfulness. Reduces the three error types by 40.1%, 79.1% and 50.0% against the strongest baseline for each, on the Mem-α validation set with a GPT-4o-mini judge. The verifier is a training reward, not an inference-time gate. *Used on slides 6, 18 and 19.*

**AIP: A Graph Representation for Learning and Governing Agent Skills.** Blumenfeld, Webber. Neo4j. arXiv:2606.04781, June 2026. Replaces free-form prose skills with a directed execution graph: steps as nodes backed by deterministic scripts or natural-language descriptions, typed input/output edges, a schema-validated YAML spec. Compiling 27 real tasks' human-written skills to AIP raised Claude Sonnet's mean task reward from 0.599 to 0.705 and pass rate from 53.3% to 67.4% (Wilcoxon p = 0.011), with wall-clock time down from 585 s to 510 s. *Used on slide 15.*

**Zep: A Temporal Knowledge Graph Architecture for Agent Memory.** Rasmussen, Paliychuk, Beauvais, Ryan, Chalef. arXiv:2501.13956, January 2025. A memory service built on Graphiti, a temporally aware knowledge-graph engine that fuses conversational and structured business data. Beats MemGPT on Deep Memory Retrieval (94.8% vs 93.4%) and reports up to 18.5% accuracy gains with 90% lower latency on LongMemEval. *Used on slide 10.*

**A-MEM: Agentic Memory for LLM Agents.** Xu, Liang, Mei, Gao, Tan, Zhang. arXiv:2502.12110, February 2025. A Zettelkasten-style memory: each new memory becomes a structured note with context, keywords and tags, is linked to related historical notes, and can trigger updates to them ("memory evolution"). Improvements over baselines across six foundation models. Links are similarity-based rather than typed. *Used on slide 10.*

**Autonomous Integration and Improvement of Robotic Assembly using Skill Graph Representations.** Yu, Huang, Chawla, Shi, Li, Liu. Carnegie Mellon University. arXiv:2603.12649, March 2026. A framework for robotic assembly that unifies system configuration, execution, evaluation and learning within one Skill Graph representation, reducing manual engineering when integrating new tasks and improving over time. *Used on slide 21 as the independent witness from robotics.*

**Agent Workflow Memory.** Wang, Mao, Fried, Neubig. arXiv:2409.07429, September 2024. Induces commonly reused routines ("workflows") from past trajectories and provides them selectively to guide later actions. Relative success-rate improvements of 24.6% on Mind2Web and 51.1% on WebArena. *Used on slide B1.*

**Reflexion: Language Agents with Verbal Reinforcement Learning.** Shinn et al. arXiv:2303.11366, March 2023. Agents reflect verbally on task feedback and keep the reflective text in an episodic buffer for later trials; 91% on HumanEval. **Generative Agents: Interactive Simulacra of Human Behavior.** Park et al. arXiv:2304.03442, April 2023. Agents store a full natural-language record of experience and synthesise it over time into higher-level reflections. **ExpeL: LLM Agents Are Experiential Learners.** Zhao et al. arXiv:2308.10144, August 2023, AAAI-24. Gathers experiences across a collection of training tasks, extracts natural-language insights, and recalls them at inference with no parameter updates. **ReAct.** Yao et al. arXiv:2210.03629, October 2022. Interleaves reasoning traces and actions. *All used to date the ladder on slide B1 (and ReAct on the cut vocabulary slide).*

**William Lyon, *Actionable Knowledge with Context Graphs*.** Talk at AI Engineer's World's Fair, 2026; slides at graphstuff.com/actionknowledge; also Going Meta S03E10 with Jesús Barrasa (26 September 2026). Thesis: agents are brilliant and amnesiac; a context graph gives memory persistence, structure to generalise over, and provenance; distillation is the compiler from memory into governed, reusable procedural knowledge (skills). Tells the billing-dispute / incident-management war story that motivated the coherence gate. **William Lyon, *From Agent Memory to Portable Skills*.** Neo4j blog, 6 August 2026. The seven-stage NAMS distillation pipeline (scope, snapshot, consolidate, graph, synthesize, gates, persist); grounding ≥ 0.9, coverage ≥ 0.6, coherence, spec lint, PII; "the graph, not the model, is the authority on what exists"; drift detection against current tool-call status and bounded repair; AIP graph-vs-prose numbers. *Used on slides 11, 13, 15 and 18.*

**Jesús Barrasa, *The Enterprise Knowledge Layer*.** Neo4j blog, 2026. Defines the knowledge layer as a shared, governed substrate between data assets and agents, tools and applications, made of three pillars: Ontologies (domain model, systems metadata, business rules), Data (reference, domain, virtual graphs), Memory (long and short term, procedural, context graph). Contrasts KL with an ontology-based semantic layer alone. *Used on slide 22.*

**Context-graph-demo evals.** `~/src/context-graph-demo`, `backend/evals/results/eval_20260921_221040.md` and `docs/decision-sop-with-jev.md`, 21 September 2026. Twenty credit-limit cases (ten customers at $5,000 and $25,000) across four arms. Tool-loop agent: 68.3 s mean, 5.3 tool calls. Fixed evidence plan with Jev deciding and Claude on escalation: 26.1 s end to end, Jev verdict alone about 3 s, 0 tool calls, 14 decided by Jev and 6 escalated, 20/20 agreement with Claude reading the same evidence. Your own data; unpublished. *Used on slide 15.*

**TypeSafe, Jev documentation and launch post.** typesafe.ai, September 2026. Jev returns typed decisions (choice, score, boolean) with probability distributions and a confidence, trained with an undisclosed method the company calls RLCD and described as calibrated. No published calibration curves. *Used on slide 15.*

## 4. Method and limits

Each arXiv paper was checked against its abstract page; where the slide carries a number or an affiliation not in the abstract (ReMe's table, BREW's benchmark breakdown and affiliations, AIP's full results, TrustMem's verifier role, sleep-time and CMU affiliations), the HTML full text was read. Lyon's talk was checked from the plain-text export of the slide deck the deck links to; the Going Meta episode page has no transcript, so nothing was checked against the video itself. Barrasa's post and Lyon's blog post were read directly. The context-graph-demo numbers were read from the eval markdown and design doc in that repo.

Not checked: the exact ACL 2026 Findings acceptance of ReMe and RecMem beyond the arXiv pages' own venue notes; whether the SKILL-KD, TrustMem, AMD or continual-learning papers are peer-reviewed (all are 2026 preprints as of this check); and the "decades" claim about trajectory vocabulary in RL and robotics on the cut vocabulary slide, which is general knowledge rather than a citation.
